## Before signing in

### Sign in

Email and password, Google sign-in, fingerprint sign-in once enabled, and Forgot password.

<img src="screenshots/app-login.png" alt="Sign in" width="260">

### Create an account

Self-registration creates a normal user only; there is no role field. The department is chosen from a list.

<img src="screenshots/app-register.png" alt="Create an account" width="260">

### Verify your email

A 6-digit code is emailed; the account stays locked until it is entered.

<img src="screenshots/app-verify-dialog.png" alt="Verify your email" width="260">

### Forgot password - email

Enter the email address to receive a 6-digit code.

<img src="screenshots/app-forgot-password.png" alt="Forgot password - email" width="260">

### Forgot password - code and new password

Enter the emailed code and choose a new password.

<img src="screenshots/app-forgot-code.png" alt="Forgot password - code and new password" width="260">

### Choose your own password

Accounts created by an admin must replace the temporary password before using the app.

<img src="screenshots/app-change-password.png" alt="Choose your own password" width="260">

## User

### User dashboard

A user sees only their own tickets, with total, open and resolved counts, search and filters.

<img src="screenshots/app-user-dashboard.png" alt="User dashboard" width="260">

### Create a ticket

Title, description, category, priority and an optional attachment. The ticket is assigned automatically to the technician with the fewest open tickets.

<img src="screenshots/app-submit-ticket.png" alt="Create a ticket" width="260">

### Ticket detail

Status, priority, SLA due date, comments and the history of every change.

<img src="screenshots/app-ticket-detail.png" alt="Ticket detail" width="260">

### Is it really fixed?

Once resolved, only the owner can confirm the fix or reopen the ticket with a reason.

<img src="screenshots/app-confirm.png" alt="Is it really fixed?" width="260">

### Reopen with a reason

The owner says what is still wrong; the ticket returns to Open.

<img src="screenshots/app-reopen-dialog.png" alt="Reopen with a reason" width="260">

### Rate the service

After the fix the owner can leave a star rating and a comment.

<img src="screenshots/app-rating.png" alt="Rate the service" width="260">

### Live chat support

Chat with CloudDesk Support (Gemini answers for staff; built-in replies for users).

<img src="screenshots/app-chat.png" alt="Live chat support" width="260">

### Analytics

Ticket counts by status, priority and category as graphs.

<img src="screenshots/app-analytics.png" alt="Analytics" width="260">

### Help and FAQ

Answers to common questions.

<img src="screenshots/app-faq.png" alt="Help and FAQ" width="260">

### Profile menu

The menu changes with the role: users see fewer items than admins.

<img src="screenshots/app-profile-menu.png" alt="Profile menu" width="260">

### Settings

Name, phone, password change, notifications, fingerprint sign-in, language and theme.

<img src="screenshots/app-settings.png" alt="Settings" width="260">

## Technician

### Update a ticket

Change the status, use canned replies, comment, and notify the owner by email or SMS.

<img src="screenshots/app-tech-ticket.png" alt="Update a ticket" width="260">
